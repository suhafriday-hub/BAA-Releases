Приложение сопоставляет исходный файл и финальный файл научной статьи.

Системные требования:
- Windows 10 или Windows 11, 64-разрядная система;
- Microsoft Word для подготовки страниц DOCX с исходным оформлением;
- интернет для ИИ-рецензий и загрузки обновлений;
- для ИИ-рецензий используется собственный API-ключ пользователя.

Страницы прокручиваются колёсиком мыши: в конце страницы открывается следующая, в начале — предыдущая. Ctrl + колесо меняет масштаб. Текст выделяется мышью и копируется через Ctrl+C. Стрелки изменений переходят к отличающимся фрагментам.

Высота обеих панелей документов и статистики меняется общим разделителем. Сводка включает 12 показателей статьи и топ-20 слов с нумерацией. Для сравнения используются команды по словам, предложениям и абзацам.

Исходные файлы не изменяются. Настройки и API-ключ сохраняются отдельно от установленной программы. Имя служебной папки Batch Article Analyzer сохранено для совместимости с предыдущими установками.

Кнопка «Обновить» проверяет официальный канал GitHub. После подтверждения установщик загружается, проверяется по SHA-256, устанавливает новую версию и снова открывает приложение.

Полный Word-отчёт содержит таблицу параметров исходной и финальной статьи, разницу и процент изменения, рецензию с отдельными пунктами и топ-20 слов каждой версии. Количество страниц определяется по готовому просмотру Word: откройте оба документа и дождитесь показа страниц перед сохранением отчёта. Без готового просмотра указывается «Н/д». Нераспознанные разделы также отмечаются «Н/д»; дату поступления программа не угадывает по дате файла.

Сводный Excel содержит относительные ссылки на Word-файлы. Переносите Excel вместе со всей папкой отчётов, сохраняя расположение файлов. Для ранее созданной сводки сформируйте новый Excel-отчёт. Порядок файлов учитывает числа: 1, 2, …, 10.
Сравнение статей 2.4.7

1. Откройте пару статей и выберите «ИИ и отчёты» → «ИИ-рецензия текущей пары».
2. Промпт формирует краткие ключевые отличия: не более 10 предложений и 120 слов.
3. Нажмите «Сохранить отчёт пары». Word-файл содержит таблицу показателей и краткую сводку по шаблону. Заголовок: «Отчёт пары: 1», имя файла: «Отчёт пары. 1.docx». Двоеточие в имени файла заменено точкой по правилам Windows.
4. Для журнала сначала создайте отчёты всех пар через «ИИ и отчёты» → «Создать отчёты по всем парам…».
5. Выберите «ИИ и отчёты» → «Сформировать отчёт по всему журналу». Получится один Word-файл с суммами показателей, краткой сводкой и составом журнала. Для каждого показателя указано число учтённых пар. Неизвестные значения, отсутствующие и устаревшие отчёты не считаются нулями.

При смене исходных документов сначала перегенерируйте отчёты пар. Повторное сохранение добавляет суффикс _2, _3. Топ-20 слов остаётся в окне «Сводка изменений»; компактный Word-отчёт следует новому шаблону. Для чтения старого формата DOC требуется Microsoft Word: приложение создаёт служебную копию DOCX, сохраняя оригинал.

Даты поступления, принятия к публикации и публикации берутся из полного текста статьи. Если дата не указана или оставлен шаблон, в таблице стоит «Не указана». Дата принятия не считается датой публикации.

Модель по умолчанию: OpenAI GPT-6 Luna (`openai/gpt-6-luna`, https://polza.ai/models/openai/gpt-6-luna). При ошибке HTTP 401 укажите действующий ключ Polza в настройках. Команда «Сохранить таблицу и вывод текущей пары…» сохраняет готовые данные без нового запроса к ИИ.

Тест соединения ожидает ответ до 60 секунд. Причина ошибки отображается рядом с кнопкой. При превышении времени ожидания повторите проверку: такая задержка не означает неверный ключ.
Сравнение статей 2.4.7

В приложении и Word используется единый набор: слова в названии, аннотации, ключевых словах, основном тексте и заключении; разделы и подразделы; рисунки, таблицы, источники; английские и русские символы. Модель — OpenAI GPT-6 Luna (openai/gpt-6-luna) через Polza AI. В Windows запросы используют системный HTTPS с проверкой сертификатов. API-ключ хранится защищённо в профиле пользователя. HTTP 401 означает, что провайдер отклонил ключ; при задержке соединения можно повторить проверку. Причина ошибки показана рядом с кнопкой теста.

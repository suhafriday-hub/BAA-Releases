Сравнение статей 1.0.0

Правообладатель: Ширинбегзода Сухайлии Илхом. Самарский университет.

Установка
Запустите BAA-1.0.0-Setup.exe. При переходе с прежних выпусков, в том числе с большим номером версии, используйте этот установщик. Пользовательские настройки сохраняются.
Нужны Windows 10 (1809 или новее) либо Windows 11, x64. Microsoft Word требуется для просмотра с исходным оформлением и чтения старых DOC. Интернет и собственный API-ключ нужны для ИИ-рецензии; расчёт показателей и общий отчёт выполняются без ИИ.

Работа с приложением
1. В меню «Документы» откройте исходную и финальную статьи или папки с файлами.
2. Выберите сравнение по словам, предложениям или абзацам. Колесо мыши прокручивает страницы, Ctrl + колесо меняет масштаб, Ctrl+C копирует выделенный текст.
3. Сводка показывает 13 показателей: авторов; слова в названии, аннотации, ключевых словах, основном тексте и заключении; разделы, подразделы, рисунки, таблицы, источники; английские и русские символы. Отдельная строка содержит даты поступления и принятия из статьи и разницу в календарных днях.
4. «ИИ и отчёты» → «ИИ-рецензия текущей пары» показывает количественные выводы и проверенные текстовые свидетельства. Неподтверждённые цитаты модели отбрасываются. Числа рассчитываются по тем же данным, что и таблица. Это не экспертиза научной достоверности.
5. «Создать отчёты по всем парам…» сохраняет отдельные Word-отчёты. Из окна рецензии также можно сохранить отчёт пары.
6. «Сформировать отчёт по всему журналу» пересчитывает все пары и создаёт единый Word-файл: сводная страница, затем отчёты пар по числовому порядку. Отдельные отчёты также сохраняются. Для 12 пар выпуска 2026.3 общий документ содержит 13 страниц.

Оформление и расчёты
Word-отчёты содержат таблицы без блока «Ключевые отличия». Все границы чёрные, шапки серые и жирные, текст ячеек выровнен по центру горизонтально и вертикально.
Изменение равно 0.0% при одинаковых значениях, включая 0 → 0. При ненулевой исходной величине используется (финальное − исходное) / исходное × 100%. Рост от нулевой базы не имеет определённого процента. Для дат в колонке «Изменение, %» стоит «-».
Неизвестные показатели не подменяются нулями. Сводная таблица показывает число учтённых пар для каждого показателя.
Повторное сохранение создаёт новый файл с числовым суффиксом. Исходные статьи не изменяются. Excel-сводку переносите вместе с папкой отчётов, чтобы сохранить относительные ссылки.

Обновления и лицензия
Кнопка «Обновить» проверяет официальный канал GitHub; установщик проверяется по SHA-256. Настройки и ключ хранятся отдельно от программы.

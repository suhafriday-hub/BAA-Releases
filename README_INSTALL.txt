Правообладатель: Ширинбегзода Сухайлии Илхом
Организация: Самарский университет

Приложение сопоставляет исходный файл и финальный файл научной статьи.

Системные требования:
- Windows 10 или Windows 11, 64-разрядная система;
- Microsoft Word для подготовки страниц DOCX с исходным оформлением;
- интернет для ИИ-рецензий и загрузки обновлений;
- для ИИ-рецензий используется собственный API-ключ пользователя.

Страницы прокручиваются колёсиком мыши: в конце страницы открывается следующая, в начале — предыдущая. Ctrl + колесо меняет масштаб. Текст выделяется мышью и копируется через Ctrl+C. Стрелки изменений переходят к отличающимся фрагментам.

Высота обеих панелей документов и статистики меняется общим разделителем. Сводка включает 16 показателей статьи и топ-20 слов с нумерацией. Для сравнения используются команды по словам, предложениям и абзацам.

Исходные файлы не изменяются. Настройки и API-ключ сохраняются отдельно от установленной программы. Имя служебной папки Batch Article Analyzer сохранено для совместимости с предыдущими установками.

Кнопка «Обновить» проверяет официальный канал GitHub. После подтверждения установщик загружается, проверяется по SHA-256, устанавливает новую версию и снова открывает приложение.

Условия лицензии приведены в LICENSE_RU.txt. Условия сторонних компонентов — в папке licenses.


Сравнение статей 2.4.2

Полный Word-отчёт содержит таблицу параметров исходной и финальной статьи, разницу и процент изменения, рецензию с отдельными пунктами и топ-20 слов каждой версии. Имя отчёта совпадает с именем исходного файла; при повторном сохранении добавляется _2, _3 и далее. Исходные документы не переименовываются.

Количество страниц определяется по готовому просмотру Word: откройте оба документа и дождитесь показа страниц перед сохранением отчёта. Без готового просмотра указывается «Н/д». Нераспознанные разделы также отмечаются «Н/д»; дату поступления программа не угадывает по дате файла.

Сводный Excel содержит относительные ссылки на Word-файлы. Переносите Excel вместе со всей папкой отчётов, сохраняя расположение файлов. Для ранее созданной сводки сформируйте новый Excel-отчёт. Порядок файлов учитывает числа: 1, 2, …, 10.

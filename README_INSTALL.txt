# Сравнение статей 1.2.0

Правообладатель: Ширинбегзода Сухайлии Илхом. Самарский университет.

Установка
Запустите BAA-1.2.0-Setup.exe из этой поставки. При каждом запуске сохраняются только настройки нейросети. Папки документов и отчётов нужно выбрать заново.
Требуются Windows 10 (1809 или новее) либо Windows 11, x64. Microsoft Word нужен для просмотра страниц, чтения DOC и количественных отчётов с подсчётом страниц. Для семантической рецензии нужны интернет и API-ключ настроенной модели. Количественные показатели рассчитываются без ИИ.

Выбор папок
В меню «Документы» четыре пункта:
1. Папка исходных файлов.
2. Папка финальных файлов.
3. Папка для кратких отчётов.
4. Папка для полных отчётов.
Папки результатов выбираются независимо и действуют в текущем сеансе. После нового запуска пути пусты. Уже сохранённые файлы не удаляются.

Формирование отчётов
На панели два меню: «Семантический отчёт» и «Количественный отчёт». В каждом сначала «Сформировать и сохранить краткий отчёт», затем «Сформировать и сохранить полный отчёт». Команды обрабатывают все сопоставленные пары журнала. Файл начинается с титульника и оглавления, далее включает сводку и результаты каждой статьи. Документы без пары тоже включаются: показатели рассчитываются для имеющейся версии, сравнение изменений не выполняется. Вид анализа указан в имени файла, объём определяет выбранную папку сохранения. Повторное сохранение создаёт новый файл. Отдельные кнопки под панелью убраны.

Семантическая рецензия
ИИ анализирует изменённые фрагменты с контекстом и выделяет расширение содержания, сокращение, уточнение смысла, редакционные правки и другие содержательные изменения. Краткая рецензия показывает до трёх содержательных наблюдений каждой статьи; полная — все проверенные наблюдения с цитатами двух версий. Если модель не выделила содержательных изменений, краткая версия показывает редакционные правки. Оба вида используют полный набор найденных текстовых изменений для анализа, а не сокращённый входной текст.
Программа проверяет структуру ответа, охват фрагментов, цитаты и числа в выводах. При некорректном ответе выполняется одна повторная попытка; после повторной ошибки отчёт не выдаётся как готовый. Интерпретация и классификация остаются оценкой ИИ. Это не экспертиза научной достоверности. Изображения и неизвлечённые встроенные объекты не анализируются.
Для переключения между краткой и полной версиями в текущем запуске используется уже проверенная рецензия, если файлы и настройки модели не изменились. При закрытии приложения текущая операция отменяется.

Количественный отчёт
Краткий и полный отчёты используют единый буквенный подсчёт слов: без чисел, отдельных знаков, DOI/URL, заглушек XXX/ХХХ, идентификаторов с цифрами и подчёркиванием и единиц после чисел. Полный отчёт дополнительно показывает слова в заголовках, подписях и таблицах данных, статистику Word со всем содержимым и слова текстовых объектов рисунков. Код учитывается отдельно. Текст растровых изображений не распознаётся.
Основной текст — от первого основного раздела до заключения. Введение и заключение считаются отдельно. Формулы включают нумерованные, ненумерованные отдельные выражения и встроенные объекты Word/MathType; каждый вид показан отдельно. Добавлены предложения (оценка), абзацы, числовые значения, аннотации, сноски, примечания, слова в них и в колонтитулах, разделы финансирования и вклада авторов. Строки определяет Word после разметки. Количество страниц определяется для всего файла статьи после разметки Word; в сводке страницы суммируются. Это не количество страниц отчёта.
Таблицы количественного отчёта нумеруются последовательно: 1 — сводка, 2 и далее — статьи. Границы чёрные, шапка серая и жирная, текст по центру. Нулевое изменение — 0.0%; между датами считаются дни, процент обозначен «-».

Сравнение на экране
Меню «Сравнить» позволяет сопоставить слова, предложения или абзацы. Колесо мыши прокручивает страницы, Ctrl + колесо меняет масштаб, Ctrl+C копирует выделенный текст. Настройки модели находятся во вкладке «Нейросеть» окна настроек.

Управление интерфейсом
Кнопка «Синхронная прокрутка» связывает движение страниц в обеих панелях; повторное нажатие отключает связь. В меню «Очистить» пункт «Очистить всю таблицу» убирает список и открытые документы, сохраняя файлы на диске. Чтобы загрузить список снова, выберите папку документов.

Оформление по умолчанию — системное. Числовые параметры нейросети можно менять кнопками «−» и «+». «Применить» сразу вводит изменения в действие. Ограничения длины документа в символах в настройках нет; семантическая рецензия обрабатывает изменения по частям без обрезки общего текста.

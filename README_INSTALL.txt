Batch Article Analyzer 2.2.0

Правообладатель: Ширинбегзода Сухайлии Илхом
Организация: Самарский университет

Системные требования:
- Windows 10 версии 1809 или новее либо Windows 11, 64-разрядная система;
- доступ к интернету требуется только для внешних ИИ-функций и обновлений;
- API-ключ пользователь получает и вводит самостоятельно.

Установщик размещает программу в профиле текущего пользователя, создаёт запись для удаления и ярлык в меню «Пуск». Ярлык на рабочем столе можно выбрать в мастере установки. Права администратора не требуются.

Настройки хранятся отдельно от программы:
%APPDATA%\Batch Article Analyzer\settings.ini

При удалении приложения пользовательские настройки и защищённый API-ключ сохраняются, чтобы обновление или повторная установка не уничтожали конфигурацию. Их можно удалить вручную из указанной папки.

Кнопка «Обновить» проверяет официальный канал BAA на GitHub, загружает новую версию и запускает обновление поверх установленной копии. Перед запуском установщика обязательно проверяется SHA-256.

Приложение поставляется без исходных файлов Python. Исполняемый файл оптимизирован и содержит сведения о версии и авторских правах. Абсолютно исключить копирование или анализ программы технически невозможно; правовая защита определяется лицензионным соглашением, а доверие Windows — цифровой подписью правообладателя, если она будет добавлена.

Перед передачей неопубликованной статьи внешнему API проверьте адрес сервиса, его политику конфиденциальности и допустимость передачи материала.

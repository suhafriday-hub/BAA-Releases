# Сравнение статей

<img src="logo.png" width="96" alt="Сравнение статей">

Приложение для сопоставления исходных и финальных версий научных статей в Word. Формирует краткие и полные количественные отчёты и семантические рецензии.

Правообладатель: **Ширинбегзода Сухайлии Илхом**, **Самарский университет**.

## Скачать и установить

Текущая версия — **1.1.0**.

[Скачать установщик для Windows](https://github.com/suhafriday-hub/BAA-Releases/releases/download/v1.1.0/BAA-1.1.0-Setup.exe) · [Описание выпуска](https://github.com/suhafriday-hub/BAA-Releases/releases/tag/v1.1.0)

Запустите установщик и следуйте инструкциям. При обновлении пользовательские настройки сохраняются. В установленном приложении доступна проверка обновлений.

Требуются Windows 10 (1809 или новее) либо Windows 11, x64. Microsoft Word нужен для просмотра страниц, чтения DOC и количественных отчётов с подсчётом страниц. Для семантической рецензии нужны интернет и API-ключ настроенной модели. Количественные показатели рассчитываются без ИИ.

## Что изменилось в 1.1.0

- Уточнён подсчёт слов: числа, знаки, DOI, адреса, технические идентификаторы и заглушки исключаются из слов.
- Код и формулы учитываются отдельно; улучшено распознавание таблиц, разделов и библиографии.
- Добавлены показатели предложений, абзацев, аннотаций, сносок, примечаний, колонтитулов, финансирования и вклада авторов.
- Исправлены названия выпусков и оформление сводных таблиц отчётов.

Проверка версии: 122 автоматических теста, 72 документа (36 пар), шесть количественных отчётов и запуск собранного приложения.

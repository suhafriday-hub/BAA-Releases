# Сравнение статей

<img src="logo.png" width="96" alt="Сравнение статей">

Приложение для сопоставления исходного файла и финального файла научной статьи. Сохраняет оформление страниц Word, позволяет выделять и копировать текст и показывает изменения прямо на страницах.

Правообладатель: **Ширинбегзода Сухайлии Илхом**. Организация: **Самарский университет**.

## Скачать и обновить

Текущая версия — **2.4.1**. [Скачать установщик для Windows](https://github.com/suhafriday-hub/BAA-Releases/releases/download/v2.4.1/BAA-2.4.1-Setup.exe).

Если приложение уже установлено, нажмите **«Обновить»**, подтвердите загрузку и установку. Программа проверит файл по SHA-256, установит новую версию и запустится снова. Настройки сохраняются.

## Работа с файлами

1. В меню «Документы» откройте исходный файл и финальный файл либо выберите папки с файлами.
2. Нажмите «Сравнить» и выберите сравнение по словам, предложениям или абзацам.
3. Прокручивайте страницы колёсиком мыши. В конце страницы открывается следующая; при прокрутке вверх от начала — предыдущая. Ctrl + колесо меняет масштаб.
4. Выделяйте текст мышью и копируйте Ctrl+C. Стрелки изменений переходят между отличающимися фрагментами.
5. Общий разделитель под документами меняет высоту обеих панелей и статистики.
6. «Сводка изменений» показывает 16 показателей статьи и топ-20 слов с нумерацией.

Количество рисунков и таблиц определяется по уникальным номерам подписей, а структура — по заголовкам и стилям DOCX. Нераспознанные показатели обозначаются «Не определено». Подробности доступны при наведении на строку. «Похожие подписи таблиц и рисунков» проверяет сходство подписей, а не содержимое изображений.

## Требования

Windows 10 версии 1809 и новее или Windows 11, x64. Для подготовки страниц DOCX с исходным оформлением нужен установленный Microsoft Word. При его отсутствии доступен извлечённый текст. Первое открытие нового файла требует подготовки; готовые страницы сохраняются в локальном кэше.

Интернет нужен для обновлений и ИИ-рецензий. ИИ используется по явному согласию с собственным API-ключом. Исходные файлы не изменяются.

# Batch Article Analyzer

Правообладатель: **Ширинбегзода Сухайлии Илхом**  
Организация: **Самарский университет**

BAA сравнивает исходную и доработанную версии научных статей, подсвечивает изменения, проверяет возможные повторы таблиц и рисунков, формирует DOCX/XLSX-отчёты и при явном согласии пользователя создаёт ИИ-рецензию через выбранный OpenAI-совместимый API.

## Скачать

Скачайте **BAA-2.2.0-Setup.exe** в разделе [Releases](https://github.com/suhafriday-hub/BAA-Releases/releases/latest). Переносимая версия доступна там же.

После установки дальнейшие версии можно получать кнопкой **«Обновить»** в приложении.

Поддерживаются Windows 10 версии 1809 и новее и Windows 11 x64. Интернет нужен только для ИИ-рецензии и проверки обновлений. API-ключ в приложение не включён.

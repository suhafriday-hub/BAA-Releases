# Сравнение статей

<img src="logo.png" width="96" alt="Сравнение статей">

Приложение для сопоставления исходных и финальных версий научных статей в Word. Формирует краткие и полные количественные отчёты и семантические рецензии.

Правообладатель: **Ширинбегзода Сухайлии Илхом**, **Самарский университет**.

## Скачать и установить

Текущая версия — **1.2.0**.

[Скачать установщик для Windows](https://github.com/suhafriday-hub/BAA-Releases/releases/download/v1.2.0/BAA-1.2.0-Setup.exe) · [Описание выпуска](https://github.com/suhafriday-hub/BAA-Releases/releases/tag/v1.2.0)

Запустите установщик и следуйте инструкциям. При каждом запуске сохраняются только настройки нейросети; рабочие папки выбираются заново. В установленном приложении доступна проверка обновлений.

Требуются Windows 10 (1809 или новее) либо Windows 11, x64. Microsoft Word нужен для просмотра страниц, чтения DOC и количественных отчётов с подсчётом страниц. Для семантической рецензии нужны интернет и API-ключ настроенной модели. Количественные показатели рассчитываются без ИИ.

## Что изменилось в 1.2.0

- Пустые пути и рабочая область при каждом запуске; настройки нейросети сохраняются.
- Синхронная прокрутка документов, очистка всей таблицы и индикаторы обработки.
- Титульник и оглавление в отчётах; документы без пары тоже включаются с отметкой об отсутствии версии.
- Системная тема, упрощённая таблица, кнопка «Применить» и кнопки «−»/«+» для числовых параметров нейросети.
- Убрано ограничение длины документов в символах. Семантическая рецензия обрабатывает все изменения по частям.

Проверка версии: 126 автоматических тестов, включая отдельный запуск 22 сценариев интерфейса. Отчёт с полной парой и документом без пары проверен в Word/PDF.

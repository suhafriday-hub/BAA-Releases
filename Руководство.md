# Сравнение статей

<img src="logo.png" width="96" alt="Сравнение статей">

Приложение для сопоставления исходного файла и финального файла научной статьи. Сохраняет оформление страниц Word, позволяет выделять и копировать текст и показывает изменения прямо на страницах.

Правообладатель: **Ширинбегзода Сухайлии Илхом**. Организация: **Самарский университет**.

## Скачать и обновить

Текущая версия — **1.0.0**. [Скачать установщик для Windows](https://github.com/suhafriday-hub/BAA-Releases/releases/download/v1.0.0/BAA-1.0.0-Setup.exe).

Для перехода на версию **1.0.0** запустите установщик по ссылке выше. При переходе с прежних выпусков с большим номером версии также запустите этот установщик вручную. Настройки сохраняются. Следующие обновления можно устанавливать кнопкой **«Обновить»** в приложении; загруженный файл проверяется по SHA-256.

## Работа с файлами

1. В меню «Документы» откройте исходный файл и финальный файл либо выберите папки с файлами.
2. Нажмите «Сравнить» и выберите сравнение по словам, предложениям или абзацам.
3. Прокручивайте страницы колёсиком мыши. Страницы идут непрерывной лентой с общей полосой прокрутки. Ctrl + колесо меняет масштаб.
4. Выделяйте текст мышью и копируйте Ctrl+C. Стрелки изменений переходят между отличающимися фрагментами.
5. Общий разделитель под документами меняет высоту обеих панелей и статистики.
6. «Сводка изменений» показывает 13 показателей статьи и топ-20 слов с нумерацией.

Количество рисунков и таблиц определяется по уникальным номерам подписей, а структура — по заголовкам и стилям DOCX. Нераспознанные показатели обозначаются «Не определено». Подробности доступны при наведении на строку. «Похожие подписи таблиц и рисунков» проверяет сходство подписей, а не содержимое изображений.

## Требования

Windows 10 версии 1809 и новее или Windows 11, x64. Для подготовки страниц DOCX с исходным оформлением нужен установленный Microsoft Word. При его отсутствии доступен извлечённый текст. Первое открытие нового файла требует подготовки; готовые страницы сохраняются в локальном кэше.

Интернет нужен для обновлений и ИИ-рецензий. ИИ используется по явному согласию с собственным API-ключом. Исходные файлы не изменяются.

## Отчёты и проверка результатов 1.0.0

Исправлен анализ английских и русских статей, включая нестандартные стили заголовков, римскую нумерацию разделов и библиографию. Добавлен подсчёт авторов. Таблицы для размещения формул и рисунков не считаются таблицами данных.

Нулевое изменение всегда равно 0.0%, включая переход 0 → 0. При росте от нулевой базы процент не определён. Между датами поступления и принятия рассчитываются календарные дни; процент к календарным датам неприменим. Используются первичные метаданные статьи, затем их перевод, если значение отсутствует. Некорректная последовательность дат отмечается ошибкой.

«ИИ-рецензия текущей пары» показывает структурированные количественные выводы, рассчитанные по полным документам. ИИ предлагает короткие цитаты изменённых фрагментов; перед показом проверяется наличие каждой цитаты в соответствующем разделе. Неподтверждённые утверждения модели не публикуются. Это проверка чисел и текстовых свидетельств, а не автоматическая экспертиза научной достоверности статьи.

«Сформировать отчёт по всему журналу» самостоятельно пересчитывает все выбранные пары и сохраняет единый Word-файл: сводная страница по образцу, затем отчёты пар по порядку. Для выпуска 2026.3 — 13 страниц. Блок «Ключевые отличия» отсутствует во всех Word-отчётах. Таблицы имеют чёрные границы, серую жирную шапку и выравнивание по центру. Процент изменения дат обозначается знаком «-». Отчёты пар также сохраняются отдельно. Сохраняется выгрузка сводки в Excel. Команда «Сохранить таблицу и вывод текущей пары» удалена; сохранение из окна рецензии остаётся.

Для обновления запустите BAA-1.0.0-Setup.exe. Пользовательские настройки сохраняются.

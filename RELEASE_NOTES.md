# Сравнение статей 1.0.0

Исправлен анализ английских и русских статей, включая нестандартные стили заголовков, римскую нумерацию разделов и библиографию. Добавлен подсчёт авторов. Таблицы для размещения формул и рисунков не считаются таблицами данных.

Нулевое изменение всегда равно 0.0%, включая переход 0 → 0. При росте от нулевой базы процент не определён. Между датами поступления и принятия рассчитываются календарные дни; процент к календарным датам неприменим. Используются первичные метаданные статьи, затем их перевод, если значение отсутствует. Некорректная последовательность дат отмечается ошибкой.

«ИИ-рецензия текущей пары» показывает структурированные количественные выводы, рассчитанные по полным документам. ИИ предлагает короткие цитаты изменённых фрагментов; перед показом проверяется наличие каждой цитаты в соответствующем разделе. Неподтверждённые утверждения модели не публикуются. Это проверка чисел и текстовых свидетельств, а не автоматическая экспертиза научной достоверности статьи.

«Сформировать отчёт по всему журналу» самостоятельно пересчитывает все выбранные пары и сохраняет единый Word-файл: сводная страница по образцу, затем отчёты пар по порядку. Для выпуска 2026.3 — 13 страниц. Блок «Ключевые отличия» отсутствует во всех Word-отчётах. Таблицы имеют чёрные границы, серую жирную шапку и выравнивание по центру. Процент изменения дат обозначается знаком «-». Отчёты пар также сохраняются отдельно. Сохраняется выгрузка сводки в Excel. Команда «Сохранить таблицу и вывод текущей пары» удалена; сохранение из окна рецензии остаётся.

Для обновления запустите BAA-1.0.0-Setup.exe. Пользовательские настройки сохраняются.

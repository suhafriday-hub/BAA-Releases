# Сравнение статей 1.2.0

1.2.0 — 03.10.2026

При запуске сохраняются только параметры нейросети; папки документов и отчётов, оформление и расположение панелей сбрасываются.
Добавлены синхронная прокрутка двух документов, очистка всей таблицы и индикаторы обработки: процент готовности для измеримых этапов и индикатор ожидания для подготовки Word/ответа ИИ.
В отчёты добавлены титульник и оглавление с переходами к статьям. Документы без пары включаются в оба вида отчётов: количественные показатели рассчитываются для имеющейся версии, семантическое сравнение отмечается как недоступное. Отсутствующая версия не заменяется нулевыми показателями.
Фирменная тема заменена на системную. Убраны пункт размера текста без оформления, ограничение символов документов, команда проверки похожих подписей и столбцы статуса, краткого ИИ-вывода и ссылки на отчёт. Длинные документы извлекаются полностью; семантическая рецензия обрабатывает все найденные изменения по частям.
В настройках нейросети добавлены кнопки «−» и «+», кнопка «Сохранить» переименована в «Применить». Закрытие контекстного меню кликом не переключает выбранную пару. Исправлено завершение отложенной проверки обновлений при закрытии окна.

Проверка: 126 автоматических тестов и 22 сценария интерфейса; отчёт с полной парой и документом без пары проверен в Word/PDF.
